# User Rating Prediction - Monster Hunter
Ongoing front-to-back machine learning project. Scrapes user ratings and franchise data from various online sources. Full pipeline handles data acquisition, storage, transformation, feature engineering and ML model construction. Allows to predict user preferances of in-game objectives (monsters) for future entries to the *Monster Hunter* video game franchise.
